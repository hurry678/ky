## 1. 推荐方向

**论文题目（候选）**：《面向大模型智能体记忆系统的可验证遗忘方法研究》

**故事线**：LLM Agent 普遍引入长期记忆（`mem0`、`Letta/MemGPT`、`A-MEM` 等），记忆中存有大量用户隐私。GDPR 被遗忘权、《个人信息保护法》第 47 条均要求"可删除"。但删掉一条记忆 ≠ 真的遗忘——信息可能残留在派生摘要、用户画像、微调过的模型参数、多智能体共享记忆中，且用户无法验证平台真删了。论文解决两个问题：

1. 怎么定义和度量"忘干净了" → 创新点 1（AI 实验）
2. 怎么让用户相信"确实删了" → 创新点 2（轻密码 + 系统）

四位一体：机器遗忘 + 大模型 + 密码 + Agent，且每块难度在单兵作战能力半径内。

## 2. 两个创新点

### 创新点 1：Agent 记忆遗忘的传播建模与彻底性评估

- **做什么**：建立 Agent 记忆的信息传播模型（原始记忆 → 派生记忆如摘要/反思/画像 → 模型参数 → 多智能体共享），提出分层"遗忘彻底性"评估方法。
- **怎么做**：
  - 记忆库层：注入 canary（金丝雀）记忆，删除后用探测 query 检验是否还能被检索到、是否还影响回答。
  - 参数层：对微调过的模型做 QA 探针、补全攻击、成员推断攻击（`Min-K% Prob` 等 MIA 方法）测残留。
  - 对比三种删除策略的泄露残留：只删条目 / 级联删除派生记忆 / 级联删除 + 参数遗忘（LoRA 上跑 `GA`/`NPO` 等轻量遗忘算法）。
  - 增强实验（就业导向）：记忆投毒（memory poisoning）清除——注入恶意记忆后展示"级联删除 + 参数遗忘"可清除，即"遗忘即防御"。同一份数据支撑合规与安全两种叙事。
- **产出**：评估工具包 + 对比实验。纯实验驱动，风险低，4090 够用（1.5B–3B 全参微调，7B 用 LoRA）。

### 创新点 2：基于哈希链与 Merkle 承诺的遗忘审计协议

- **做什么**：给记忆系统设计"遗忘可审计"机制，平台删除后给用户一张**可验证的遗忘凭证**。
- **怎么做**：
  - 记忆操作写入追加式哈希链日志；记忆库状态定期做 Merkle root 承诺（签名背书，可选上链或可信时间戳）。
  - 删除时生成凭证：删除操作日志位置、删除前后状态承诺、派生条目级联删除清单；用户可独立重放验证。
  - 威胁模型覆盖平台作恶（假删、删后恢复、选择性出示日志），论证篡改可检测性、不可抵赖性、前向完整性。
  - 与创新点 1 绑定：将模型 checkpoint 哈希、遗忘评估结果纳入承诺，防止"日志说删了但模型没忘"。
- **密码含量**：哈希链、Merkle 树、数字签名、（可选）Pedersen 承诺。工程级原语，Python 几百行，**不需要零知识证明**。
- **产出**：协议设计 + 嵌在创新点 1 系统里的原型 + 安全性分析 + 性能开销实测。
- **答辩风险对冲**：避免被质疑"就是个日志"——靠威胁模型、性质证明、与评估结果的密码学绑定来支撑。

## 3. 被排除的方向

- **ZKP 可验证遗忘**：需要证明系统工程 + 密码理论，无导师指导单干风险极高。
- **联邦学习 + 遗忘 + 安全聚合**：离 LLM/Agent 远，与导师"大模型+"方向不符，就业叙事弱。
- **纯刷 TOFU 基准造新遗忘算法**：太卷，且无密码成分，不满足交叉要求。

## 4. 就业对准

### 岗位地图（按应届 headcount 排序）

1. **大模型应用/Agent 工程师**：岗位量最大，考 RAG、Agent 框架、记忆系统设计、工程落地——基本盘。
2. **大模型安全（红队/攻防/评测）**：中等且增长，考 prompt injection、数据泄露、投毒、评测。
3. **AI 治理/隐私技术岗（合规技术侧）**：少但增长快，大厂治理部、金融机构，要求"懂法规 + 能落地"。
4. **隐私计算/数据安全**：密码味最重，核心岗要真密码背景，不作主投。

策略：主赛道 Agent 工程师，用"安全 + 合规"叙事差异化突围。

### 最贴近的论文（开题前需精读确认差异化）

- `Agentic Unlearning: When LLM Agent Meets Machine Unlearning`（2026-02）——标题最接近，**必须精读**（本次因 API 限流未获取摘要）。
- `Forgetting Without Restarting: Execution-State Unlearning for Stateful LLM Agents`（2026-09-04）——Agent 运行时状态遗忘。
- `When Unlearning Fails: Reliable Data Deletion under Post-Training in Agent Networks`（2026-07）——联邦自进化 Agent 网络的轨迹级删除（已读摘要，场景不同：他们做联邦持续学习的模型/轨迹层，我们做单机记忆库 + 审计）。
- `Selective Forgetting: A Graph-Based Memory Framework for Long-Term LLM Agents`（2026-08-29）——疑似性能驱动的记忆管理，需确认。
- `MemSecBench: Tracking Agent Memory Poisoning from Persistence to Consequence and Repair`（2026-07-29）——投毒 benchmark，含"修复"环节，需确认。
- `MemLeak: Diagnosing Information Leaks in Multimodal Agent Memory`（2026-06-29）——泄露诊断，佐证评估侧价值。
- `Auditable Machine Unlearning for Privacy-Compliant Ransomware Detection`（2026-07-07）——"auditable unlearning"提法已出现，但场景完全不同。
- `zkUnlearner: A Zero-Knowledge Framework for Verifiable Unlearning`（2025-09）——ZK 路线，我们以轻量路线差异化。

### 检索结论

- 精确组合（Agent 记忆 + 遗忘评估 + 密码审计）**无人占据**，新颖性成立。
- 但相邻领域 2026 年快速升温，窗口期估计 6–12 个月，核心实验应在 2027 年暑假前完成。
- 论文标题建议收窄，突出"记忆系统"与"审计/合规"，避免与 Agentic Unlearning 正面撞车。
